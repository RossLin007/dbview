

## 背景
我是生命教练，我举办了一个线上晨读营，晨读营通过腾讯会议开展，晨读营的交流记录被记录在会议系统（腾讯会议）上，并且转录保存在postgres 数据库中。
晨读营每天都有读书会书有有很多的分享，这些分享被转录成了文字，记录在数据库当中，现在保存着5-60位书友的分享，大概总共有7-8000片的文章，我的需求是，需要有个系统可以快速的搜索数据？开发一个系统，这个系统可以给我结果，
例如，它能够回答：

- 查询型："林泰君昨天说了什么？"
- 统计型："林泰君今年一共发言多少次？"
- 分析型："林泰君最近三个月关注的话题发生了哪些变化？"
- 关系型："谁和林泰君讨论 AI 最多？"
- 趋势型："晨读营近半年的热门主题趋势。"
- 推理型："根据最近一个月的讨论，哪些书友最适合参加生命教练课程？"


## 需求
开发一个数据库浏览器，方便我做各种查询
目标：

用户输入一句自然语言，例如：

"帮我查询一下林泰君昨天说的内容"

AI 自动完成：

1. 理解用户意图
2. 理解数据库 Schema
3. 自动选择需要查询的数据表
4. 自动生成 SQL
5. 执行 SQL
6. 必要时执行 RAG 向量检索
7. 汇总结果
8. 用自然语言回答用户

整个系统需要支持不断扩展，而不是写死 SQL。
